# ✦ Lenormand Secrets

Site institucional e catálogo digital desenvolvido para a **Lenormand Secrets**, com foco em experiência do usuário, identidade visual e organização de serviços.

🔗 **Site:** [ellebaralhocigano.com](https://ellebaralhocigano.com)

---

## 📌 Sobre o projeto

O **Lenormand Secrets** é uma aplicação web desenvolvida para apresentar serviços de leitura de Baralho Cigano, organizar um catálogo de atendimentos e facilitar o processo de agendamento.

O projeto foi desenvolvido considerando tanto os aspectos técnicos quanto a experiência visual da aplicação, desde a definição da identidade visual até a implementação das páginas e componentes.

---

## 🛠️ Tecnologias utilizadas

* **React**
* **Vite**
* **JavaScript**
* **React Router**
* **CSS3**
* **HTML5**
* **Git**
* **GitHub**

---

## 🎨 Interface e experiência

O projeto possui uma identidade visual própria baseada em:

* Roxo
* Dourado
* Vermelho
* Branco

A interface utiliza componentes reutilizáveis, navegação entre páginas, cards interativos, layout responsivo e elementos decorativos desenvolvidos especificamente para a identidade do projeto.
